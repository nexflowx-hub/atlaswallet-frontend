# AtlasWallet Frontend V1 — Z.AI bundle

Supply the JSON and master prompt to Z.AI, together with the current AtlasWallet visual mockup.

- `atlaswallet_frontend_v1_spec.json`: functional/product/design/API/legal source of truth.
- `ATLASWALLET_ZAI_MASTER_PROMPT.md`: direct generation prompt.
- `atlaswallet_frontend.env.example`: browser-safe environment template.

Important: existing backend routes are separated from planned MVP routes; planned operations must not be simulated as successful real transactions. Company number remains intentionally unset until confirmed.
